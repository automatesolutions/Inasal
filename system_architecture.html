🎭 Bacolod Tourist - MOGI Chatbot

Complete System Architecture & How It Works

Understanding Every File, Flow, and Feature

📋 Overview: How the Web App Works

🎯 Main User Journey

  1. User visits → frontend/src/app/page.tsx (Landing page)
  2. User clicks login → frontend/src/app/login/page.tsx (Login page)
  3. User enters phone/email → frontend/src/components/PhoneInput.tsx (Phone input component)
  4. OTP sent & verified → backend/app/routes/auth_routes.py (Authentication API)
  5. Background personality analysis starts → backend/app/personality_pipeline.py (Async job)
  6. User redirected to chat → frontend/src/app/chat/page.tsx (Chat page)
  7. Welcome message loads → frontend/src/components/MOGIChatbot.tsx (Main chatbot component)
  8. MOGI greets user → backend/app/routes/chat_routes.py → /api/chat/welcome
  9. User chats with MOGI → backend/app/chat_agent.py (LangChain agent)

☁️ Google Cloud Platform Setup Guide

📋 Prerequisites

  • Google Cloud Platform account (Sign up here)
  • Billing account enabled (free tier available)
  • Project with BigQuery and Cloud Storage APIs enabled

1Create Google Cloud Project

Steps:
  1. Go to Google Cloud Console
  2. Click project dropdown → "New Project"
  3. Enter project name: bacolod-tourist
  4. Note your Project ID (e.g., gen-lang-client-0542256476)
  5. Click "Create"

2Enable Required APIs

Enable these APIs:
  1. Go to APIs & Services > Library
  2. BigQuery API → Search → Click → Enable
  3. Cloud Storage API → Search → Click → Enable

3Create Service Account

Steps:
  1. Go to IAM & Admin > Service Accounts
  2. Click "Create Service Account"
  3. Enter name: bacolod-tourist-service
  4. Click "Create and Continue"
  5. Grant roles:
    • BigQuery Admin (or BigQuery Data Editor + BigQuery Job User)
    • Storage Admin (or Storage Object Admin)
  6. Click "Continue" → "Done"

4Create and Download Service Account Key

Steps:
  1. Click on the service account you created
  2. Go to "Keys" tab
  3. Click "Add Key" → "Create new key"
  4. Select JSON format
  5. Click "Create" - Downloads JSON file
  6. Save file in project: backend/gen-lang-client-0542256476-399081ed3dc7.json
  7. ⚠️ Important: Add to .gitignore to keep credentials secure!

5Create BigQuery Dataset

Steps:
  1. Go to BigQuery Console
  2. Click your Project ID in left sidebar
  3. Click "Create Dataset" (or ⋮ menu → Create dataset)
  4. Enter Dataset ID: bacolod_tourist or Inasal_app
  5. Select Location:
    • Multi-region: US (multiple regions in United States)
    • OR Region: us-central1
  6. Click "Create dataset"
  7. Note: Tables are created automatically on first connection
// Tables created automatically: - user_profiles // User profiles with personality traits - interaction_logs // User interaction history - recommendation_scores // Recommendation match scores - chat_logs // Chat messages and responses

6Create Cloud Storage Bucket

Steps:
  1. Go to Cloud Storage Console
  2. Click "Create Bucket"
  3. Enter Name: bacolod-tourist-storage (must be globally unique)
  4. Select Location:
    • Multi-region: US (multiple regions)
    • OR Region: us-central1
  5. Storage class: Standard
  6. Access control: Uniform
  7. Click "Create"

7Configure Environment Variables

Update backend/.env file:
# Google Cloud Platform Configuration GCP_PROJECT_ID=gen-lang-client-0542256476 GCP_CREDENTIALS_PATH=backend/gen-lang-client-0542256476-399081ed3dc7.json BIGQUERY_DATASET_ID=Inasal_app GCS_BUCKET_NAME=inasal-app-storage GCS_BUCKET_LOCATION=us // "us" for multi-region, "us-central1" for region

8Verify Setup

Test connections:
# Test BigQuery connection cd backend poetry shell poetry run python -c "from app.bigquery_client import bigquery_client; import asyncio; asyncio.run(bigquery_client.connect()); print('✅ BigQuery connected!')" # Test Cloud Storage connection poetry run python -c "from app.storage_client import storage_client; import asyncio; asyncio.run(storage_client.connect()); print('✅ Cloud Storage connected!')" # Start backend server poetry run uvicorn app.main:app --reload --port 8000 // Expected console output: ✅ Connected to BigQuery: gen-lang-client-0542256476.Inasal_app ✅ Connected to Cloud Storage: inasal-app-storage ✅ Table user_profiles ready ✅ Table interaction_logs ready ✅ Table recommendation_scores ready ✅ Table chat_logs ready

🔧 Troubleshooting

  • "Permission denied" → Verify service account has BigQuery Admin and Storage Admin roles
  • "Dataset not found" → Check BIGQUERY_DATASET_ID matches exact Dataset ID
  • "Bucket not found" → Verify GCS_BUCKET_NAME matches exact bucket name (case-sensitive)
  • "Credentials file not found" → Check GCP_CREDENTIALS_PATH is correct relative to project root

💰 Cost Considerations

  • BigQuery Free Tier: 10 GB storage + 1 TB queries per month
  • Cloud Storage Free Tier: 5 GB storage per month
  • Monitor usage in GCP Billing Console
